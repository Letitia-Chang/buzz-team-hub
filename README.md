# Team Hub demo

A demo of Team Hub for North Star AI Labs, built from `main` with
`node plugin/build.mjs --demo`. Sample people and data; Team Hub's real rules run
in memory inside Buzz. Nothing is saved or sent.

Install in Buzz: **Settings → Plugins → Manage plugins → From a Git repository**,
this repository's URL, branch `demo`. Then turn it on and open **Team Hub demo** in the dock.
